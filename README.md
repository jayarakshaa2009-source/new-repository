# SnapGrid

SnapGrid is a responsive image discovery web application built with plain HTML, CSS, and JavaScript. It allows users to search for high-resolution images within a modern and user-friendly interface.

## Design Decisions
1. **Sticky Glassmorphic Header:** Implemented a fixed top header with a subtle backdrop blur, ensuring search controls remain continuously accessible while scrolling through image grids.
2. **Category Suggestion Chips:** Integrated quick-pick category chips beneath the search box, allowing users to execute popular topic searches with a single click.
